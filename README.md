# 💌 InvitacionK-G

A modern and elegant digital wedding invitation website built with HTML, CSS, Bootstrap, and JavaScript.

This project was designed to provide guests with an interactive and memorable wedding invitation experience, including event details, RSVP confirmation, gallery sections, countdown timer, gift table information, and responsive design.

---

## ✨ Features

- 💍 Elegant wedding invitation design
- 📅 Event information and schedule
- ⏳ Live countdown timer
- 🖼️ Photo gallery section
- 📍 Location and map integration
- ✅ RSVP confirmation form
- 🎁 Gift table section
- 🌙 Dark mode support
- 📱 Fully responsive design
- ⚡ Smooth scrolling and animations
